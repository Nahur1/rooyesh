# رویش — نسخهٔ ویندوز

پوستهٔ Electron از همان کد `webapp/` استفاده می‌کند. عنوان، منوها، اعلان‌ها، آیکن و مشخصات نصب‌کننده با نام رویش ساخته می‌شوند. مسیر پروفایل و مبدأ داخلی نسخهٔ قبلی برای حفظ اطلاعات کاربران نگه داشته شده‌اند.

برای ساخت در ویندوز با Node.js نسخهٔ ۲۲ یا بالاتر:

```powershell
cd desktop
npm ci
npm run build
```

خروجی در `builds/windows-output/Rooyesh-Setup-<version>.exe` قرار می‌گیرد. متغیر محیطی `ROOYESH_VERSION` شمارهٔ ساخت محلی را تعیین می‌کند. مقدار پیش‌فرض از `desktop/package.json` خوانده می‌شود.

گردش کار `Release Rooyesh for Windows` با پوش تغییرات برنامه روی `main` یا اجرای دستی از بخش Actions شروع می‌شود. پس از موفقیت آزمون‌های منطق وب و ربات، شمارهٔ patch را از آخرین تگ نسخه افزایش می‌دهد و نصب‌کننده را در یک انتشار جدید منتشر می‌کند. تغییرات صرفاً مستندات انتشار را شروع نمی‌کنند. فایل‌های نصب اندروید از انتشارهای قبلی قابل دریافت‌اند.

[آخرین نسخهٔ ویندوز](https://github.com/Nahur1/rooyesh/releases/latest)

هنگام نصب نسخهٔ جدید، نصب‌کننده نسخهٔ ثبت‌شدهٔ قبلی رویش را شناسایی و حذف می‌کند. نسخهٔ قدیمی با نام Nava نیز با اجرای حذف‌کنندهٔ رسمی آن منتقل می‌شود. نصب برای کاربر فعلی و نصب برای همهٔ کاربران بررسی می‌شوند. نصب سراسری ممکن است تأیید دسترسی مدیر ویندوز را بخواهد. اطلاعات شخصی در پروفایل مشترک حفظ می‌شوند. اگر حذف نسخهٔ قبلی خطا بدهد، نصب متوقف می‌شود و می‌توان پس از رفع مشکل دوباره تلاش کرد.

گردش کار انتشار، ارتقا از آخرین نصب‌کنندهٔ منتشرشده، مهاجرت از Nava، استفادهٔ مجدد از مسیر نصب قدیمی، توقف در صورت خطای حذف و حفظ پروفایل را روی ماشین موقت GitHub آزمایش می‌کند. بسته‌های قابل‌حمل که در ویندوز ثبت نشده‌اند از طریق این سازوکار شناسایی نمی‌شوند.
