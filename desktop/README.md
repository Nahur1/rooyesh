# رویش — نسخهٔ ویندوز

پوستهٔ Electron از همان کد `webapp/` استفاده می‌کند. عنوان، منوها، اعلان‌ها، آیکن و مشخصات نصب‌کننده با نام رویش ساخته می‌شوند. مسیر پروفایل و مبدأ داخلی نسخهٔ قبلی برای حفظ اطلاعات کاربران نگه داشته شده‌اند.

برای ساخت در ویندوز با Node.js نسخهٔ ۲۲ یا بالاتر:

```powershell
cd desktop
npm ci
npm run build
```

خروجی در `builds/windows-output/Rooyesh-Setup-1.0.0.exe` قرار می‌گیرد. گردش کار `Build Rooyesh for Windows` در GitHub Actions همین مراحل را اجرا می‌کند و با اجرای دستی، فایل نصب را در انتشار `v1.0.0` قرار می‌دهد.
