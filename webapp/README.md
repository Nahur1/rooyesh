# رویش — نسخهٔ وب 🌿

اپ وب آرام و مینیمال برای کارها، اهداف، تمرکز، یادگیری و رشد شخصی. **بدون سرور، بدون ثبت‌نام، بدون اینترنت.**
روی کامپیوتر و موبایل کار می‌کند، راست‌چین است، تاریخ‌ها شمسی‌اند و حالت تیره هم دارد.

## اجرا
- **ساده‌ترین راه:** فایل `index.html` را با مرورگر (Chrome، Edge، Firefox یا Safari) باز کن.
- **با سرور محلی** (برای نصب به‌شکل اپ/PWA و کار آفلاین کامل):
  ```bash
  cd webapp
  node tests/serve.mjs 8080
  ```
  بعد `http://localhost:8080` را باز کن. می‌توانی پوشه را روی هر هاست ایستا (مثل GitHub Pages) هم بگذاری.

## بخش‌ها
| بخش | کارکرد |
|---|---|
| امروز | انتخاب نوع روز و زمان در دسترس، پیشنهاد «الان از کجا شروع کنم؟» با دلیل، برنامهٔ پیشنهادی، بخش‌های قابل‌تنظیم صفحه، «بازگشت آرام» بعد از چند روز غیبت |
| اهداف و پروژه‌ها | هدف ← مرحله/پروژه ← کار، قالب‌های آماده، قدم بعدی، پیشرفت و زمان صرف‌شده |
| تایمر تمرکز | پومودورو با مکث/ادامه/پایان، استراحت کوتاه و بلند، ثبت نتیجهٔ جلسه، یادداشت و خروجی‌ها (فایل، تصویر، کد، لینک، متن) |
| مرور هفتگی | آمار هفته و چهار پرسش مرور |
| فضای یادگیری | منابع، مبحث فعلی، قدم بعدی، سؤال‌ها، خروجی‌ها و زمان مطالعه |
| دفتر شخصی | حال و انرژی، افکار، اتفاقات و آموخته‌ها |
| گزارش | امروز، این هفته، این ماه، ۳۰ روز اخیر یا بازهٔ دلخواه |
| تنظیمات | پومودورو، بخش‌های صفحهٔ امروز، معیارهای پیشنهاد، تم، پشتیبان‌گیری و بازیابی |

## حریم خصوصی و پشتیبان
- همهٔ داده‌ها **فقط در همین مرورگر** ذخیره می‌شوند (localStorage و فایل‌ها در IndexedDB). هیچ چیزی به جایی فرستاده نمی‌شود.
- پاک کردن داده‌های مرورگر یعنی پاک شدن داده‌های رویش؛ پس هر از گاهی از **تنظیمات ← خروجی پشتیبان** یک فایل JSON بگیر.
- فایل پشتیبان با **ربات تلگرام رویش** سازگار است: می‌توانی آن را در ربات وارد کنی (و برعکس).

## آزمون‌ها
```bash
npm test            # ۱۳ آزمون واحد منطق اصلی (فقط Node.js ≥ 18)
npm run test:e2e    # ۲۷ آزمون مرورگری (نیاز به: npm i playwright && npx playwright install chromium)
```
نتیجه در زمان تحویل: **۱۳/۱۳ و ۲۷/۲۷ موفق**. اسکرین‌شات‌های آزمون در `tests/screenshots/` هستند.
