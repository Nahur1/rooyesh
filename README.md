# رویش (Rooyesh) 🌿 — سه نسخه

دستیار آرام و مینیمال برای کارها، اهداف، تمرکز، یادگیری و رشد شخصی؛ فارسی، راست‌چین، با تاریخ شمسی و بدون فشار و سرزنش.

| پوشه | نسخه | شروع سریع |
|---|---|---|
| `webapp/` | اپ وب (کامپیوتر و موبایل، آفلاین) | `index.html` را در مرورگر باز کن |
| `excel/` | فایل اکسل | `Rooyesh.xlsx` را باز کن و از برگهٔ «راهنما» شروع کن |
| `telegram-bot/` | ربات تلگرام | توکن BotFather را در `.env` بگذار و `node index.js` را اجرا کن |

هر پوشه یک `README.md` با توضیح کامل دارد.

## دانلود برنامه

پشتیبان‌های نسخهٔ قبلی همچنان در وب و ربات قابل بازیابی‌اند. نسخهٔ اندروید با شناسهٔ `ir.rooyesh.app` کنار برنامهٔ قبلی نصب می‌شود؛ برای انتقال اطلاعات، از برنامهٔ قبلی پشتیبان بگیر و در رویش بازیابی کن. نسخهٔ ویندوز از همان محل ذخیرهٔ اطلاعات قبلی استفاده می‌کند.

## امکانات مشترک
- «الان از کجا شروع کنم؟»: پیشنهاد هوشمند با دلیل (اولویت، برنامهٔ امروز، کار نیمه‌کاره، مهلت، ارتباط با هدف، زمان و انرژی)
- نوع روز (شلوغ/کم‌انرژی/معمولی/پرانرژی)، برنامهٔ پیشنهادی و «بازگشت آرام» بعد از چند روز غیبت
- هدف ← مرحله/پروژه ← کار، قدم بعدی و پیشرفت
- جلسهٔ تمرکز (پومودورو)، نتیجه و خروجی هر جلسه
- فضای یادگیری، ایده‌ها، دفتر شخصی، مرور هفتگی و گزارش زمان
- منطق پیشنهاد در وب و ربات **یک فایل مشترک** است (`webapp/core.js` = `telegram-bot/src/core.cjs`) و فرمول‌های اکسل همان منطق را بازسازی می‌کنند.
- فایل پشتیبان JSON وب و ربات با هم **سازگار** است.

## نتیجهٔ آزمون‌ها (در زمان تحویل)
| نسخه | آزمون | نتیجه |
|---|---|---|
| وب | ۱۳ آزمون واحد (`npm test`) + ۲۷ آزمون مرورگری با Playwright/Chromium در دسکتاپ و موبایل | ۴۰/۴۰ موفق |
| ربات | ۲۰ آزمون (`npm test`): همهٔ صفحه‌ها و جریان‌ها، پیمایش خودکار بیش از ۱۲۰ دکمه، اعتبارسنجی HTML و محدودیت‌های تلگرام، و آزمون HTTP با سرور شبیه‌ساز Bot API | ۲۰/۲۰ موفق |
| اکسل | بازمحاسبهٔ ۱۲٬۸۳۸ فرمول، بازبینی ساختار، بررسی مقادیر نمونه و بازبینی ظاهری همهٔ برگه‌ها | ۰ خطا |

## محدودیت‌ها
- **وب:** داده‌ها فقط در همان مرورگر می‌مانند؛ مرتب پشتیبان بگیر.
- **اکسل:** تایمر زنده ندارد؛ جلسه‌ها دستی ثبت می‌شوند.
- **ربات:** Node.js ۱۸ به بالا و سروری که به api.telegram.org دسترسی داشته باشد لازم است. روی تلگرام واقعی با توکن اجرا نشده؛ با شبیه‌ساز Bot API آزمایش شده است.
