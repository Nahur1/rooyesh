# ناوا — ربات تلگرام 🌿

نسخهٔ تلگرامی ناوا: همان دستیار آرام برای کارها، اهداف، تمرکز، یادگیری و دفتر شخصی — داخل تلگرام.
بدون هیچ وابستگی خارجی؛ فقط Node.js لازم است.

## راه‌اندازی (حدود ۵ دقیقه)

۱. **ساخت ربات:** در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده، دستور `/newbot` را بفرست، یک نام و یک یوزرنیم (با پایان `bot`) انتخاب کن و **توکن** را کپی کن.

۲. **نصب Node.js نسخهٔ ۱۸ یا بالاتر** (از nodejs.org). بررسی: `node -v`

۳. **تنظیمات:** فایل `.env.example` را به `.env` کپی کن و توکن را بگذار:
```
BOT_TOKEN=توکن_BotFather
ALLOWED_USERS=شناسهٔ_عددی_خودت
```
> شناسهٔ عددی‌ات را نمی‌دانی؟ موقتاً `ALLOWED_USERS=0` بگذار، ربات را اجرا کن و به آن پیام بده؛ ربات شناسهٔ عددی‌ات را نشان می‌دهد. آن عدد را جایگزین ۰ کن و ربات را دوباره اجرا کن. (راه دیگر: [@userinfobot](https://t.me/userinfobot)). حتماً این مقدار را پر کن تا ربات فقط برای خودت کار کند.

۴. **اجرا:**
```bash
cd telegram-bot
node index.js
```
پیام «ناوا روشن شد» یعنی همه‌چیز آماده است. در تلگرام به رباتت `/start` بفرست.

> اگر تلگرام در شبکه‌ات مسدود است، ربات را روی یک سرور خارج از ایران اجرا کن، یا `API_BASE` را روی یک پراکسی معکوس Bot API تنظیم کن.

### همیشه روشن ماندن (اختیاری)
- با **pm2**: `npm i -g pm2 && pm2 start index.js --name nava && pm2 save`
- یا با **systemd** یک سرویس بساز که `node /path/to/telegram-bot/index.js` را اجرا کند (`WorkingDirectory` را پوشهٔ ربات بگذار).

## حریم خصوصی
- داده‌ها فقط در پوشهٔ `data/` روی همان سیستمی که ربات را اجرا می‌کنی ذخیره می‌شوند (یک فایل JSON برای هر کاربر). سرویس دیگری در کار نیست.
- فایل‌ها و عکس‌هایی که می‌فرستی روی سرورهای تلگرام می‌مانند و ربات فقط شناسهٔ آن‌ها را نگه می‌دارد؛ هنگام «گرفتن پشتیبان» خودِ فایل‌ها (تا ۴۰ مگابایت) داخل پشتیبان قرار می‌گیرند.
- با `ALLOWED_USERS` ربات فقط به تو جواب می‌دهد و در گروه‌ها کار نمی‌کند.
- اعلان مزاحم نمی‌فرستد؛ تنها پیام خودکار، پایان جلسهٔ تمرکز یا استراحتی است که خودت شروع کرده‌ای.

## هماهنگی با نسخهٔ وب
فایل پشتیبان ربات و نسخهٔ وب یک قالب دارند: پشتیبان ربات را در نسخهٔ وب (تنظیمات ← بازیابی) باز کن یا برعکس — فایل‌های پیوست هم منتقل می‌شوند.

## آزمون‌ها
```bash
npm test
```
۲۰ آزمون: ۱۷ سناریوی کامل کاربر (با یک API جعلی که HTML، طول پیام و دکمه‌ها را مثل تلگرام بررسی می‌کند، به‌علاوهٔ پیمایش خودکار همهٔ دکمه‌های قابل‌دسترس) و ۳ آزمون یکپارچه با یک سرور HTTP شبیه‌ساز تلگرام (long polling، آپلود multipart، دریافت فایل).
